# 📌 Abrasiletrando

Hello, this is a project that I developed with two more friends at SENAI. The Abrasiletrando is a website for brazilians teenagers that's studying for the finals exams such as ENEM and entrance exams. In this website they will find a lot of content that will help them with their studies in brazilian literature by offering simplified and engaging multimedia resources to facilitate the understanding of brazilian literature.

You can access the website in this link: https://devjuvenilson.github.io/abrasiletrando/

---

## 🚀 Features

- "Movimento" page that guide the student to know better about the all 12 literature movement.
- "Estante Virtual" page that shows to the user all required literary works demanded by universities.
- Multimedia resources to facilitate the understanding and to engage the student.
